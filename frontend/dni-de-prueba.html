DNI de prueba

Códigos PDF417 con datos ficticios, con el mismo formato que el frente del DNI tarjeta, para probar la verificación de identidad del registro. Abrí esta página en la computadora y escaneá el código con la app en el celular (Registro → “Escanear mi DNI”). Los profesionales coinciden con las fichas del padrón de prueba del seed.

No son documentos reales ni sirven fuera de esta app. Cada código abre una sola cuenta: para volver a usarlo, corré npm run db:seed en el backend.
